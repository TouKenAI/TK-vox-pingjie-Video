# 文案类型配置包（Genre Profiles）· V8.0 多类型泛化核心规范

> 本文件是多文案类型适配的**唯一事实源**。流水线各环节（detect_genre 识别 → check_script 机检 →
> TTS 情绪档 → SUT 视觉策略 → BRIEF 契约）全部从本文件取参数。新增类型 = 在本文件加一节 +
> 在 `check_script.py GENRE_LIMITS` / `detect_genre.py GENRE_RULES` 各加一行对应记录。
>
> 设计原则：①类型只换"配置"，不换"机制"（五道门禁/账本/零复用/时长红线全部通用）；
> ②每种类型 = 识别特征 + 骨架库 + 节奏参数 + emotion 映射 + CTA 规范 + 合规清单 + 视觉策略；
> ③识别不确定时 WARN 让人工 `--genre` 显式指定，**禁止硬猜硬配**。

## -1. V3.21 长度规范变更 + V3.22 语速清账（覆盖下文各类型的「字数/时长/speed」）

**① 长度**：各类型档案里的 `字数 280~360 / 时长 80~100s / 信息点 ≤12` 一类数字，自 **2026-09-20 起降级为参考值，不再是门禁**。
用户决定：**不限字数、不限时长，以用户给的文案为准，不砍内容**；`check_script` 默认不套上下限，`GENRE_LIMITS` 里的预算字段 V3.22 已删除。
**② 语速（V3.22 清账）**：下文各类型"节奏"行曾按 genre 写 `hook 1.0 / build 1.05 / climax 0.95 / 低谷 0.9 / 0.85` 这类**每类型三档以上**的 speed——**全部作废**，它们违反用户 2026-09-18 定死的两档制。
唯一合法取值：**build 段 1.15、其余（hook/context/proof/climax/cta）一律 1.1**，与 genre 无关；genre 只决定 `emotion` 标签与 CTA 措辞。
实测口径：1.1 档 4.90 字/秒、1.15 档 5.15 字/秒（≈294~309 字/分），`check_script` 据此打印预计时长。语速**不用来凑时长**（时长由文案自然决定）。
类型仍然决定：CTA 措辞机检、广告法红线（ad）、骨架库、视觉策略，以及 **R4 单句 ≤45 字**这条可读性硬门。
语速仍只有 **1.1 / 1.15 两档**。

## 0. 通用 emotion 标签（全类型统一，向后兼容）

旧书评标签 → 通用标签（generate_tts/check_script 内部映射，旧 chunks 无需改动）：

| 通用标签 | 旧标签别名 | 语义 | TTS 基调 |
|---|---|---|---|
| hook | hook | 开场钩子 | 沉稳克制，反差词加重，比整体收一点 |
| context | book | 背景/对象介绍 | 清晰自然，不赶 |
| build | method | 主体推进（方法/卖点/情节） | 干脆利落，条理清晰 |
| proof | case | 证据（案例/数据/演示/证言） | 叙述感，数字处放慢强调 |
| climax | quote | 情绪顶点（金句/高潮/承诺） | 比整体慢半拍，一字一顿 |
| cta | cta | 行动引导 | 亲切上扬 |

## 1. knowledge 知识口播（默认 · 书评/科普/政策解读/行业分析）

- **识别特征**：出现书/作者/概念/方法/研究/政策/文件/通知；结构为"观点+论证"；数字为引用型（数据/年份/倍数）
- **骨架库**（三选一轮换，连续两片不同）：
  A 清单式（钩子→书/对象→三个方法→案例→金句→CTA）
  B 答案前置式（开场甩结论→为什么拆三段→回扣结论）
  C 双线对比式（两条线交叉→中点揭晓→合并教训）
- **节奏**：参考字数 280~380（**V3.21 起不设限，非门禁**）；参考时长 95~100s；语速**两档制（V3.15 用户规范）：build 1.15 / 其余（hook·context·proof·climax·cta）一律 1.1**，禁止第三档与提速兜底；信息点不设上限；SFX ≤20
- **CTA**：关注类（"关注我/收藏"），屏显可加互动钩
- **合规清单**：事实点清单（声明|原文依据|压缩/演绎方式），演绎项必标注
- **视觉策略**：概念隐喻驱动（抽象概念→动词性动画图腾），核心图腾贯穿首尾；数字句必 A 级可视化

## 2. ad 营销广告（产品/服务促销、活动推广）

- **识别特征**：限时/优惠/折扣/立即/点击/下单/免费/名额/倒计时；承诺式措辞；CTA 为交易动作
- **骨架库**（二选一轮换）：
  A PAS 式（痛点→放大代价→方案登场→证据→促销 CTA）
  B AIDA 式（注意→兴趣→渴望→行动）
- **节奏**：参考字数 240~320（V3.21 不设限）；参考时长 60~90s；语速**两档制：build 1.15 / 其余 1.1**（~~220~260 字/分, hook 1.0/build 1.05/climax 0.95~~ V3.22 作废，第三档违反两档制）；SFX ≤16
- **CTA**：交易类（"立即抢购/点击下方/领取"），**CTA 前必须有利益点 recap**
- **合规清单**：**广告法红线机检**——绝对化用语（最/第一/唯一/国家级/100%）、虚假承诺（稳赚/包过/永不）、
  医疗金融未 disclaim；命中即 ERROR 要求改写（detect 在 check_script --genre ad 启用）
- **视觉策略**：**产品英雄镜头**（产品居中放大+光环/burst）+ 使用场景代入 + Before/After 对比；
  痛点段用"问题具象化"（把痛点画成正在发生的损失）；促销信息用烫金大字卡

## 3. brand 品牌宣传（企业/个人品牌形象、价值观、愿景）

- **识别特征**：我们/品牌名/相信/愿景/使命/初心/一路/同行；无直接促销；情绪价值优先
- **骨架库**（二选一轮换）：
  A 世界观式（我们相信…→三个信念递进→愿景画面→同行邀请）
  B 历程式（起点→转折→坚持→今天→未来）
- **节奏**：参考字数 260~340（V3.21 不设限）；参考时长 80~100s；语速**两档制：build 1.15 / 其余 1.1**（~~180~220 字/分, hook 0.9/build 0.95/climax 0.85~~ V3.22 作废；本类型"慢氛围"靠 `instruction` 措辞与场间留白实现，不靠降 speed 档）；SFX ≤12（克制，重氛围）
- **CTA**：认同类（"一起/同行/见证"），弱 CTA 或无 CTA 均可（profile 允许 `cta_required=false`）
- **合规清单**：品牌事实核验（成立时间/数据/里程碑需用户确认来源），无硬机检
- **视觉策略**：**情绪意象 + 品牌符号**（一个核心符号物贯穿，如灯塔/树/桥）；明度渐变叙事
  （由暗到明或由冷到暖）；动效舒缓（drift/缓缩为主，burst 全片 ≤1）；大字少而重

## 4. story 叙事故事（人物故事、事件复述、情感短剧）

- **识别特征**：人称主角（他/她/我）+ 时间标记（那年/后来/直到）；情节冲突；情感弧线
- **骨架库**（二选一轮换）：
  A 三幕式（日常→冲突爆发→低谷→转折→和解/领悟）
  B 倒叙式（结局前置→回到起点→重走关键三步→回到结局释然）
- **节奏**：参考字数 300~380（V3.21 不设限）；参考时长 90~110s；语速**两档制：build 1.15 / 其余 1.1**（~~190~230 字/分, 日常 1.0/冲突 1.05/低谷 0.9/转折 0.95~~ V3.22 作废；情节变速改用 `instruction` 相对语速措辞 + 场间留白，不改 `speed` 档）；SFX ≤18（环境音氛围优先）
- **CTA**：共鸣类（"你有过吗/评论区讲讲"），或开放式无 CTA
- **合规清单**：真人真事需用户确认授权/化名；虚构声明可选
- **视觉策略**：**角色连续性第一**（同一角色多姿态 --ref 保一致）；场景即情绪（每个情节点一个场景色温）；
  关键转折用"设计性跃变"；物件图腾（一个道具承载情感，首尾呼应）

## 5. product 产品介绍（功能讲解、新品发布、教程演示）

- **识别特征**：这款/它/功能/参数/搭载/支持/一键/秒；名词为产品部件；动词为功能动作
- **骨架库**（二选一轮换）：
  A FAB 式（场景痛点→特性→优势→利益→演示→CTA）
  B 拆解式（整体亮相→三大功能逐个演示→参数汇总→CTA）
- **节奏**：参考字数 280~360（V3.21 不设限）；参考时长 80~100s；语速**两档制：build 1.15 / 其余 1.1**（~~210~250 字/分, hook 1.0/build 1.05/climax 0.95~~ V3.22 作废）；SFX ≤18（功能点配 UI 音效）
- **CTA**：了解类（"了解详情/进店看看/预约体验"）
- **合规清单**：参数/功能点必须与官方资料一致（用户供资料或标注来源）；对比竞品禁贬损
- **视觉策略**：**功能拆解可视化**（每个功能 = 一个独立"演示小场景"，产品剖面/爆炸图/部件飞行组装）；
  参数用滚数/翻牌；使用场景前后对比；UI 元素可做"界面卡"（深色底+亮色线框）

## 6. 流水线各环节消费方式

| 环节 | 消费内容 |
|---|---|
| `detect_genre.py` | §1-5 识别特征打分，输出 genre+置信度；<0.6 置信 WARN 让人工定 |
| `check_script.py` | 按 genre 取 **CTA 措辞 + 广告法机检开关**（V3.21 起不取长度预算；另按实测语速打印预计时长） |
| `generate_tts` | emotion 通用标签映射 + **两档 speed（build 1.15 / 其余 1.1，与 genre 无关）** |
| SUT/BRIEF | 按视觉策略设计隐喻/英雄镜头/角色连续方案；骨架写入 BRIEF 首行 |
| `qa_deliver` | 合规清单类型入交付报告（知识=事实点核对过 / 广告=违禁词机检过） |
