# 开工模板（下一部片起，开工必填）

> **用法**：新建 `productionN` 后，把本文件复制为 `productionN/KICKOFF.md`，逐条填。
> **A、B、D、F 四部分全填完才进生图。填不出来的项 = 这场要重想或合并，不许空着过。**
> **填写顺序**：开工时 `0 → A → B → C → D → F`；渲完后再填 `E`。（F 排在 E 前是有意的——防千篇一律要在动手前查，第一眼检查在出片后查。）
> 这 12 条管的是"画什么、怎么动"，不是检测。检测拦不住画得空、动得平。
> **本模板管"怎么填"，不管"填成一样"**——A1/A2/B 全是空格不是预设，F 部分专门防止两部片长得像。

---

## 0. 适配起点（先做这一步，再填 A）

**0-1 · 跑类型识别，取本类型的视觉策略当起点（是起点，不是答案）**
```bash
py -3.14 scripts/detect_genre.py <项目目录>   # 置信<0.6 必须人工 --genre 指定
```
从 `references/genre-profiles.md` 抄下本类型「视觉策略」那一行（knowledge=概念隐喻+核心图腾贯穿 / ad=产品英雄镜头+Before/After / brand=情绪意象+明度渐变+舒缓动效 / story=情节意象+环境氛围）：

填：本类型视觉策略 = ______________________________

**0-2 · 题材三问（这三条决定世界、配色温度、动效快慢）**
- 这篇文案的**主角物**是什么（一个具体的东西，不是概念）：______
- 它最自然的**物理动作**是什么（拆/装/烧/冻/涨/漏/锁/传…）：______
- 它的**情绪温度**是什么（冷 / 暖 / 紧 / 松）：______

→ A1 的"世界"要从**主角物和物理动作**长出来；A2 的三个特征要从**题材**长出来；动效快慢跟**情绪温度**走（紧=快砸快切，松=慢漂慢推）。**不许从上一部抄。**

## A. 全片三定（动笔前，先写这三行）

**A1 · 这部片发生在什么地方？**（一句话。必须是有光、有空间、有前后层的场面）
> 例：亮着台灯的工作台一角 / 贴满便签的墙 / 深夜亮屏的房间
> 禁止：一张纸上画几笔、纯空白底、只有边框线

填：______________________________________________

**A1b · 每场一个空间（V3.34 新增，硬门 `bg_plan_check`）**
> 背景不是墙纸，是**这场戏发生的那个空间**。一部片里同一张背景出现 3 次以上，
> 观众就不再相信"这是另一个地方"，画面显薄。实测分界：p11–p16 独立背景/场数 = 1.00，
> p18–p23 = 0.15–0.45（同一张墙轮用 5–10 次）——和用户"后面都不如 p11"的判断完全对上。
> 而且"每场都要重新描述空间"会逼出**有内部体积的背景**（摊位/柜台内景/货架间/房间），
> 而不是"一面贴了装饰的墙"（p11 bg_s08 是建筑，p23 bg_store_front 是墙，目检差异就在这）。
> 生图前：`jobs_bg*.json` 的背景条目数 ≥ 场数（`bg_plan_check --plan` 在生图章前拦）；
> 建场后：渲前链按 scene JSON 量真实复用率，门槛 0.75。
> **每张背景的 prompt 必须写清三件事**（缺一件就还是"一面墙"）：① 光从哪儿来 ② 地平线/台面在哪
> ③ **哪一块地板站得下人**。出图后拼一张 contact sheet，逐张问"能在这场里站着演吗"，不能就重抽。
> 确实全片就在一个空间（单一场景片）→ 在本文写一行 `bg_reuse_ok: <理由>`，空理由不算豁免。

填：本片 ______ 场，计划 ______ 张专属背景；被复用的场是 ______（没有就写"无"）

**A2 · 本片的风格 = 3 个看得见的特征**（生图后抽 4 张拼一起，肉眼核对三个都在才过；不在就重抽）
> 例（维修手册风）：① 零件沿一条轴线散开 ② 编号引线 ③ 剖面排线

填：① ______________ ② ______________ ③ ______________

**A2b · 运动语法**（从 `references/style-presets.md §动画语法` 抄**主风格那一行**，不许凭印象）
> 决定"像不像这个风格"的第一线索是运动，不是配色。副风格只借元素语言，**不借运动语法**。
> ⚠ **但"抄"不等于"用"**：这一行只是**下限**，抄完直接开做 = 和上一部同风格的片子动效逐字相同
> （p20→p21 就是这么发生的）。主风格与上一部相同时，必须同时填 **A2c** 说清差异在哪几场。
> **V3.41 起这条不再只管"同档"**：实测三部不同风格片缓动余弦 0.950/0.962/0.983——**换了风格档不等于换了动法**，余弦 >0.97 同样拦。

| 项 | 主风格那一行写的 | 本片填 |
|---|---|---|
| 运动质感 | | |
| 主导缓动（7 选：linear/in/out/in-out/out-back/out-expo/spring） | | |
| **禁用**缓动/动作 | | |
| 视差 开/关 | | |
| `jitter.hold`（剪纸/报纸/漫画=3~5，其余=1） | | |
| 相机（推拉方向与幅度） | | |

填：______________________________________________

**A2c · 与上一部的运动差异**（**V3.31 硬门 / V3.41 扩到跨风格**：同档、或换了档但缓动余弦 >0.97 时必填，`render_all` 渲前按**实测缓动**拦你）
> p20→p21 实录：两部都选「剪纸拼贴」，A2b 逐行照抄预设表同一行 → 落地缓动余弦 **0.983**、
> 主导缓动两部同为 `ease-out`，六道渲前门全绿，交付后用户一眼看出"这几个片子一个样"。
> **写法要求（机器校验）：≥30 字 + 点名 ≥2 个场次（`S0N`）+ 出现 ≥2 个不同动效词。**
> 一句"本片节奏更好"过不了；真做不出差异就换主风格档，或 `style_presets blend` 借副风格的 motion 落到某几场。

填：______________________________________________

**A3 · 情绪最高点的那一次"打断"用哪种？**（全片只用一次，但要狠：换色 / 撕开 / 突然放大 / 画面反转）

填：______________，出现在第 ____ 场

## B. 逐场表（每场一行）

| 场 | 台词要点 | 演什么动作<br>（七选一） | 哪个词被演出来<br>（滚/堆/喷/砸） | 重的那一下<br>在第几秒 | 视差<br>开/关 | 相机<br>推/拉 | >6s 的<br>景别切点 |
|---|---|---|---|---|---|---|---|
| S01 | | | | | | | |
| S02 | | | | | | | |
| S03 | | | | | | | |
| … | | | | | | | |

**动作七选一**：拼装 / 撕开 / 滑动 / 砸下 / 折叠 / 散开 / 沉落。写不出动作的场 = 这场是静止 PPT，合并或重想。

**填表硬规矩（填完自查）**：
- [ ] 动作列没有空格
- [ ] "被演出来"列：全片至少 **3 处**是滚/堆/喷出来的，不许全是静态字卡
- [ ] 数字滚动那 **3 处**必须用 `seq_`（`make_countup` 产物）——**p14/p15/p16 实测 `seq_` 用了 0 次**，能力一直在，是没人用
- [ ] `motes`（微粒纵深）至少用在 1 场——**实测三部片全 0 次**
- [ ] 视差列**按 A2b 的规定填**：主风格标"视差必开"的 → 至少一半场开；标"视差关"的 → **全关，别硬开**（水墨/白板/漫画/浮世绘硬开视差就露馅）
- [ ] 相机列：每场都写了推或拉（没有"不动"），且缓动形状取自 A2b，不用默认
- [ ] 全片没有出现 A2b 列出的**禁用**缓动/动作
- [ ] 超过 6 秒的场都写了景别切点（先全景后特写 / 先特写后全景）
      → **V3.41 起这条有机检**：`preflight_v6` 会把 B 表这一列与场景 JSON 的 `camera_motion.keyframes` 段数对账，
      >6s 且声明了切点、相机却只有 2 段(一镜到底) = **拒渲**。落地方式：写 `qa/beats.json` 后跑
      `py -3.14 scripts/split_beats.py productionN`（切点要落在真实短语边界上，别套固定网格）。
      确实要全片一镜到底 → 写一行 `cuts_waived: <≥20 字的理由>`，"全片一镜到底"这类套话洗不白(实测四种偷懒写法全红)。

## C. 每场五拍（做场景时对着摆，逐场填）

1. **亮相**（纸的世界 + 主动作起）：______
2. **进来一个新东西**（障碍或新层）：______
3. **重的那一下**（撞 / 撕 / 砸，全场只有一个主导）：______
4. **后果**（物理反应：碎、弹、晃、散）：______
5. **停住，但纸还在微微动**（收尾剪影要 readable）：______

规矩：落地的东西必须**压扁再弹回**，不许匀速飘进来。

## D. 画面硬规矩（四条，做场景时守着）

- **D1** 主体占画面宽度 **≥ 40%**，四周不许是大片空白。
- **D2** 底部装饰带的颜色 = 本片配色之一：__________（不许沿用模板里的旧颜色）。
- **D3** 背景 scale **≥ 1.10**，给相机留推拉余量（=1.0 时相机想动也动不了）。
- **D4 · 英雄时刻（V3.35 恢复，p17 之后五部都没做）**：全片情绪最高点那一场，建场前先手写 **2–3 个方案**再选一个磨它。
  > 这是整条产线唯一一次"为惊喜而设计"——其余都在守规格。p17 做过一次（两块菜单牌同时熄灭），
  > 之后 p18–p23 全部直接进建场，**结果就是六部片没有一处让人记住的画面**。
  - 最高点在第几场：______
  - 方案 A：______
  - 方案 B：______
  - 方案 C（可选）：______
  - 选定 + 为什么它比另外两个强：______

## E. 渲完第一眼检查（低清预览，逐场问一句）

> 观众第一眼看哪里？
> 如果不是主体 → 重摆，不要靠加元素救。

**E2 · 静音看（V3.35 新增，交付前必做一遍）**
> 关掉声音，只看画面，逐场问一句：**"这一场在讲谁？"**
> 答不出、或答出来的是另一个名字 → 语义没演出来（§66 的 Flash/Pro 事故就是这个类型，
> `name_ledger` 只查"名字在不在屏上"，查不出"这场该讲的主体没被演"）。
> 逐场记一行：场号 / 我看到了什么 / 与旁白是否同一件事。填：______

**E3 · WARN 分诊（V3.35 新增）**
> `render_all` 通过时会打印 `SUMMARY layout: hard=… | warn=PLATFORM_RAIL×N …`。
> 历史片每片 187–312 条 WARN 从来没进过人眼（=没有门）。逐类问一句"这一类里有没有真缺陷"，
> 有就改，没有就在 BRIEF 写一行"已分诊：PLATFORM_RAIL×N，理由…"。不许整类忽略。
