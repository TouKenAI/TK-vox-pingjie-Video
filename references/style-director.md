# 视觉风格总纲 · Style Director（V8.2，2026-09-08 用户裁决：三线并存+选题自动匹配+元素融合）

> 本文件是**视觉风格的唯一事实源**。任何新片在阶段①交审时必须声明"视觉风格"（主风格+客串元素），
> 由 detect_style.py 按选题自动匹配、置信 <0.6 交人工指定。风格契约与配色与 palette_ledger/novelty_meter 联动。

## 0. 体系总则

- **三风格共享 Vox 剪纸底层**：纸艺层叠材质、硬边阴影（V8.1.8 SHADOW/BIG）、光源统一（左上 45°）、
  逐帧渲染管线完全一致——切换风格只改"场景材质 + 文字卡配色 + 排版语言 + 道具语言"四件事，渲染栈零改动。
- **选题匹配优先，风格轮换兜底**：detect_style 给出主风格；同系列内允许"系列统一风格"（P15-P17 国产 AI
  叙事即 cutout 系列），跨系列必须轮换，连续 3 部同风格占比 ≤2/3（novelty_meter D6 风格维度预警）。
- **融合许可**：主风格 ≥70%，客串元素 ≤30%。融合必须服务语义（见 §3），禁止为炫技混搭。

## 1. 三风格谱系

| 维度 | cutout 主线 | chalk 黑板板书 | popup 立体书 |
| --- | --- | --- | --- |
| 场景材质 | 冷色系纸艺写实：机房/办公室/地图/产品/数据 | 墨绿黑板底+粉笔痕迹+木质粉笔槽 | 奶油/牛皮纸艺+纸机关结构+层叠 z 排序 |
| 文字卡配色 | 每片版本化（palette_ledger 校验，≥30% 色差） | 粉笔白(241,238,225)/粉笔黄(250,214,80)/粉笔红(226,84,70) | 纸深棕(48,38,30)/机关橙(205,110,40) |
| 排版语言 | 自由布局+分屏+角标钉 | 居中板书/左右分栏/划线批注/下划线强调 | 机关弹出/层层展开/纸标签并列 |
| 道具语言 | 实物隐喻（服务器/印章/图表/产品） | 粉笔/板擦/灯泡/涂鸦箭头/草稿龙 | 纸艺硅锭/芯片/晶圆/弹出机关/纸房子 |
| 数字呈现 | 大字卡+countup 增长动画 | 粉笔数字+红笔圈注 | 纸标签数字+机关翻页 |
| 金句 | 大字+radial-burst | 红粉笔大字+定格 zoom（scale 1→1.15） | 深棕大字+定格 zoom |
| 精选四维主力 | 表达力/感染力 | 获得感（老师讲课心智） | 惊喜感（纸艺立体） |
| 背景生图契约 | 场景写实纸艺（历史契约） | "chalkboard classroom, chalk dust, flat paper layers" | "pop-up book paper craft, cream paper, paper pop-out" |

## 2. 选题 → 风格自动映射（detect_style.py 规则）

| 选题类型 | 内容特征（关键词/语境） | 主风格 | 理由 |
| --- | --- | --- | --- |
| 技术原理科普 | 如何工作/机制解释/为什么/原理/接龙式比喻 | chalk | "老师讲课"心智=获得感王者（试产验证） |
| 供应链/制造/产品拆解 | 沙子→芯片/从X到Y/层层打开/工艺流程 | popup | 层级展开=立体机关天然适配（试产验证） |
| 政策/宏观/行业格局 | 政策/万亿/数据局/国家队/战略 | cutout | 冷色信息密度+多素材隐喻 |
| 公司战局/竞争 | 战局/巨头/对标/围剿/反超 | cutout | 分屏对比+实物隐喻 |
| 事件快评/热点 | 48h 时效/突发/热搜 | cutout | 默认快线，素材成本最低 |
| 大模型/算法机制 | 训练/推理/Token/参数/接龙（机制类） | chalk（或 popup 轮换） | 机制解释心智，两风格交替防疲劳 |
| 数据/趋势/量化 | 数字密集/统计/排行/涨幅 | cutout + countup | 数字增长动画在冷色场景最醒目 |
| 芯片/硬件产业链 | 光刻/封装/晶圆/代工 | popup | 试产《一颗AI芯片》已验证纸艺层级 |

置信规则：命中 1 类关键词 ≥3 处 → 置信 ≥0.7；1-2 处 → 0.5-0.7（WARN 交人工）；无命中 → 0.3（人工指定）。
chunks.json 首元素可显式锁定 `"style": "chalk"`（最高优先级）；qa/style-detect.json 缓存复用（晚于 chunks.json 即命中）。

## 3. 元素融合规则（跨风格客串）

| 触发语义 | 客串元素 | 适用 |
| --- | --- | --- |
| "划掉旧认知/反常识/纠偏" | 黑板红笔划线/✗ 批注 | cutout/popup 中客串 chalk |
| "层层拆解/从X到Y/打开" | 立体机关弹出/纸标签层 | cutout/chalk 中客串 popup |
| 数据登场/对比 | countup 数字增长卡 | 任意主风格（V8.1.8 已通用） |
| "老师在讲重点/划重点" | 粉笔下划线/圈注/分栏板书 | popup 中客串 chalk |
| 实物隐喻需求强 | cutout 写实道具贴入 | chalk/popup 主体中客串 cutout 道具 |

融合约束：主风格场景材质 ≥70% 画面面积；客串元素 ≤30% 且必须有语义动机（在 sut.json 的 visual 字段标注"客串"）；
palette_ledger 只校验主风格配色；BRIEF"视觉风格"行声明主风格+客串及理由。

## 4. 每风格启动清单（阶段④用）

- chalk：bg prompt 契约 + 卡配色三粉笔色 + 道具（chalk_stick/eraser/lightbulb）+ 金句 climax_card（红粉笔+定格）
- popup：bg prompt 契约 + 卡配色（深棕/机关橙）+ 道具（silicon_ingot/chip/wafer）+ 金句 climax_card（深棕+定格）

> **V8.2.4 信息卡可读性硬契约（P19 首版"透明底橙字叠暖背景糊成一团、重点看不出"返工教训，三风格通用）**
> 1. 文字卡**禁止纯透明底直接叠复杂/同色系背景**——必须带"实心圆角底板+细描边+柔和投影"，让字落在自己的底板上、与背景彻底分离；
> 2. **三级信息层级**：L1 普通=浅底+深字；L2 强调=浅底+高饱和强调色；L3 金句/大数字=深色实心牌+浅色字（明度强反转，全片最跳）；
> 3. popup 卡配色升级：底板奶油纸(246,239,221)、主字墨棕(46,36,27)、强调由机关橙(205,110,40)→**赤陶红(192,70,26)**（更沉、离黄更远、更跳）、L3 牌墨棕(46,36,27)+奶油字(248,241,222)、弱化灰(122,112,102)；
> 4. countup 数字必须带**深色描边**（末帧=强调色+浅色粗描边+深棕细边的双层描边），任何背景上都清晰；
> 5. 全片叠一张**去暖暗角蒙版**（中心透明、边缘中性深灰压暗；普通图层 z=1、base_width=1080、显式标 `"bg_overlay": true`；layout_check 已豁免其遮挡判定；带封面场景封面 z40 全覆盖故首帧不受影响），让背景退后、视线收向中心；
> 6. **明度对比优先于色相对比**：同色系背景+同色系字（暖底暖字/冷底冷字）明度差不足是"醒目度杀手"；先保明度分层，再谈色相风格。
- cutout：历史契约 + palette_ledger 配色版本化 + 实物道具 + countup 按需

## 5. 与精选计划四维的对应

- 获得感：chalk 知识讲解 / cutout 数据深度
- 惊喜感：popup 纸艺立体 / 金句定格 / countup
- 表达力：三风格统一大字卡+动效接力
- 感染力：真实细节（BRIEF 必交区）+ IP 讲书人三出场（cutout 为主，chalk/popup 按需）
